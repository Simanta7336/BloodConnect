## CSE470 Project

BloodConnect — Blood Donation & Emergency Finder  
BloodConnect is a web-based blood donation management and emergency donor-finding 
platform that connects blood donors, recipients, hospitals, and volunteers. The system allows 
users to search for available donors based on blood group and location, submit and track 
emergency blood requests, manage donation appointments, maintain donation history, and 
organize blood donation campaigns.  

##Main Users: 
● Donor            
● Recipient       
● Hospital         
● Admin            

##Main Users: 
- Provides blood and responds to requests
- Searches for donors and creates blood requests
- Manages blood requests and confirms donations
- Manages and monitors the entire system
